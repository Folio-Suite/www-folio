Folio Suite brings together native software projects and reusable frameworks. This development site provides a place to find their source, read API documentation, and follow notes from the work.

## Start with the documentation

[UndoKit's API documentation](/UndoKit/) includes integration guides and symbol references. The version selector lets you move between the latest documented release and retained versions. Where a topic exists in both versions, the selector keeps you on that topic.

## Explore the source

The [Folio Suite organization on GitHub](https://github.com/Folio-Suite) contains the project repositories. [Folio](https://github.com/Folio-Suite/Folio) covers the suite, while [UndoKit](https://github.com/Folio-Suite/UndoKit) maintains its own framework source and release history.

Future development notes will appear in the [dev blog](/blog/) and its [RSS feed](/feed.xml).
